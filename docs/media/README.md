# Demo media

Generated with `bash scripts/generate-demo-media.sh` using the app's production SwiftUI components and fictional printer readings.

- `overview.png`: app card, compact widget, and four menu bar styles.
- `menu-bar.png`: production menu bar dropdown rendered with two sample printers.
- `widget-small.png` and `widget-medium.png`: production widget layouts.
- `demo.mp4` and `demo.gif`: a 20-second scripted transition through printing, paused, and finished states.

These are reproducible UI demonstrations, not recordings of a physical print or evidence of continuous WidgetKit refresh. They contain no real addresses, serial numbers, credentials, or job names.
